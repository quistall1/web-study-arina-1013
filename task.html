Вычисление значения Z

Даны вещественные числа X и Y. Вычислить Z по условию:

Z = X · Y, если X > Y; иначе Z = ln(X + Y).

Ввод данных

Готово к расчёту

Результат

Введите X и Y, затем нажмите «Рассчитать».

Z = X · Y при X > Y; иначе Z = ln(X + Y).

Проверка области определения

Если X ≤ Y, аргумент натурального логарифма должен удовлетворять условию X + Y > 0. Иначе действительный результат не определён и сайт покажет предупреждение.
