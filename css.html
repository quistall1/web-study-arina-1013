Селекторы и каскад

Правила CSS состоят из селектора и деклараций. Каскад определяет, какое из конфликтующих правил применяется с учётом специфичности и порядка.

  1. Селектор тега — например p.
  2. Класс — например .card.
  3. Идентификатор — например #main.
.card {
  padding: 24px;
  border-radius: 16px;
  background: white;
}

Адаптивные макеты

Flexbox удобен для выравнивания в одном направлении, а Grid — для двумерной сетки. Медиа-запросы позволяют перестраивать колонки на узком экране.

  • Используйте относительные единицы там, где это полезно.
  • Проверяйте контраст текста.
  • Не допускайте горизонтальной прокрутки всей страницы.
