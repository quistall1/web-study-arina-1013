При создании сайта удобно идти по шагам и проверять каждый результат.

  2. Создать HTML-страницы.

  • Убедиться, что изображения отображаются.

  • Проверить работу на узком экране.

В этом проекте HTML отвечает за содержание, CSS — за внешний вид, JavaScript — за действия.
