Раздел 1. Что делает JavaScript

JavaScript позволяет странице реагировать на действия пользователя. Например, кнопка может менять текст или выполнять расчёт.

  1. Найти нужный элемент.
  2. Обработать событие.
  3. Показать результат.

Раздел 2. Пример кода

document.querySelector('button').addEventListener('click', function () {
  alert('Кнопка нажата');
});

Событие click возникает, когда пользователь нажимает на элемент.
