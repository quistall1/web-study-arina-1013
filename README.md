# Учебный сайт Курбановой Арины

Группа: БЮРЦЮ252. Индивидуальная задача: 1013.

## Страницы

- `index.html` — главная страница.
- `html.html`, `css.html`, `js.html`, `workflow.html` — информационные страницы.
- `gallery.html` — большая картинка, миниатюра и таблица.
- `forms.html` — две формы с отправкой данных на демонстрационный сервер.
- `passport-dom.html` — получение данных из DOM.
- `passport-latin.html` — перевод имени и фамилии на латиницу по нажатию кнопки.
- `task.html` — задача № 1013.

## Задача 1013

Если X > Y, то Z = X * Y. Иначе Z = ln(X + Y). Для второго случая проверяется, что X + Y > 0.

## Запуск

Откройте `index.html` в браузере. CSS, JavaScript и изображения находятся в папках `css`, `js` и `assets`.

## Публикация

В настройках репозитория откройте Settings → Pages. Выберите Deploy from a branch, ветку main и папку /(root), затем нажмите Save.
